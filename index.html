Lesson 1 · Foundations

What is a Set?

A set is a collection of distinct things. Those things can be numbers, words, objects, or even other sets.

📦 Collections and elements

Every item inside a set is called an element. We write elements between curly braces.

Fruits = {Apple, Banana, Orange} Numbers = {1, 2, 3, 4, 5}

The set Fruits has three elements. The symbol ∈ means “is an element of.”

True Apple ∈ Fruits
False Car ∈ Fruits

Not inside? Use ∉. For example, Car ∉ Fruits.

⚡ Four rules to remember

1. Sets usually use capital letters

A = {1, 2, 3} B = {Cat, Dog}

2. An empty set contains nothing

∅ = { }

3. Order does not matter

{1, 2, 3} = {3, 1, 2}

4. Repeated elements count only once

{1, 1, 2, 2, 3} = {1, 2, 3}

📏 Size of a set

The number of elements in a set is its cardinality. We write it with vertical bars.

A = {Dog, Cat, Bird} |A| = 3

Lesson 2 · Relationships

Subsets

A set is a subset of another set when every one of its elements also appears in the other set.

🗂 A smaller set inside a bigger set

Animals = {Cat, Dog, Bird, Fish} Pets = {Cat, Dog}

Every element of Pets appears in Animals, so we can write:

Pets ⊆ Animals

Read ⊆ as “is a subset of.” If even one element is missing from the larger set, it is not a subset.

Subset {2, 4} ⊆ {1, 2, 3, 4}
Not a subset {2, 5} ⊄ {1, 2, 3, 4}

🧠 The subset test

Look at each element in the smaller set and ask: Does it also appear in the bigger set?

CandidateSubset of A?Reason
{2, 5}YesBoth are in A
{1, 6}No6 is missing
{ }YesThe empty set is always a subset

Here, A = {1, 2, 3, 4, 5}.

📌 Two special rules

Every set is a subset of itself

A ⊆ A

The empty set is a subset of every set

∅ ⊆ A

There are no elements in ∅ that could break the subset rule.

Lesson 3 · Combinations

Power Sets

The power set of X is the set of every possible subset of X—including the empty set and X itself.

⚙️ A set made of sets

Suppose X = {A, B}. Its power set is written 𝒫(X).

𝒫(X) = { { }, {A}, {B}, {A, B} }

A normal set contains elements. A power set contains entire subsets as its elements.

🔢 How many subsets?

A set with n elements always has 2ⁿ subsets. Each element has two choices: included or not included.

|𝒫(X)| = 2ⁿ

🧪 Build a power set

Turn the elements on or off. The lab lists every possible subset of your chosen set.

🎲 Why power sets matter

In probability, X is the sample space of all outcomes. An event is a subset of X, so it is also one element of 𝒫(X).

X = {Sunny, Rainy, Snowy} U = {Rainy, Snowy} U ⊆ X and U ∈ 𝒫(X)

Lesson 4 · Combining Sets

Set Operations

Set operations let us combine sets, find what they share, or remove elements. The three essentials are union, intersection, and difference.

Learning objectives

By the end of this lesson, you will be able to:

  • Combine sets using union (∪)
  • Find common elements using intersection (∩)
  • Remove elements using difference (− or \)
  • Solve simple set-operation problems

➕ 1. Union (∪)

The union combines every element from both sets. Think: “Everything in A or B.”

A = {1, 2, 3} B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

The number 3 appears only once because a set never counts duplicate elements.

Start A: 1 2 3
B: 3 4 5
Combine A ∪ B: 1 2 3 4 5

🎯 2. Intersection (∩)

The intersection contains only elements that appear in both sets. Think: “Common elements.”

A = {1, 2, 3} B = {3, 4, 5}
A ∩ B = {3}

Only 3 belongs to both A and B.

Compare A: 1 2 [3]
B: [3] 4 5
Keep common items A ∩ B: 3

➖ 3. Difference (−)

The difference starts with one set and removes every element found in the other set.

A = {1, 2, 3, 4} B = {3, 4, 5}
A − B = {1, 2}

Start with A, then remove 3 and 4 because they also occur in B.

B − A = {5}

Direction matters: A − B and B − A are usually different.

🍎 One example, three operations

A = {Apple, Banana, Mango} B = {Banana, Orange}
OperationMeaningResult
A ∪ BEverything{Apple, Banana, Mango, Orange}
A ∩ BCommon elements{Banana}
A − BIn A, but not B{Apple, Mango}
B − AIn B, but not A{Orange}

🌟 Memory trick

SymbolOperationRemember
∪UnionCombine everything
∩IntersectionCommon elements only
−DifferenceStart on the left, remove the right

📝 Worked practice

Let A = {1, 2, 3, 4} and B = {3, 4, 5, 6}.

A ∪ B = {1, 2, 3, 4, 5, 6} A ∩ B = {3, 4} A − B = {1, 2} B − A = {5, 6}

🎲 Why this matters

Set operations appear throughout probability. If two events U and V do not overlap, then their intersection is empty:

U ∩ V = ∅

The probability of either event occurring is then the sum of their individual probabilities:

P(U ∪ V) = P(U) + P(V)

Union tells us either event; intersection tells us whether the events overlap.

Lesson 5 · Pairing Sets

Cartesian Product

A Cartesian product pairs every element of one set with every element of another set. These ordered pairs are the bridge from sets to functions.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a Cartesian product is
  • Write and interpret ordered pairs
  • Find the Cartesian product of two sets
  • Calculate the number of ordered pairs
  • Explain why A × B is generally different from B × A

✖️ 1. What is a Cartesian product?

The Cartesian product of A and B is the set of all possible ordered pairs whose first value comes from A and second value comes from B.

A × B

Read this as “A cross B.” Pair every element of A with every element of B.

Imagine a multiplication table: every row meets every column, and each meeting creates one ordered pair.

📍 2. Ordered pairs

An ordered pair has two positions. The first value comes from A; the second comes from B.

(1, A)
First from A, second from B (1, A)
Different order (A, 1)

Order matters: (1, A) ≠ (A, 1).

🧩 3. Pair every element

A = {1, 2} B = {A, B}

Start with 1 and pair it with both elements of B. Then repeat with 2.

A × B = { (1, A), (1, B), (2, A), (2, B) }
From AFrom BOrdered pair
1A(1, A)
1B(1, B)
2A(2, A)
2B(2, B)

🎨 4. Colors and shapes

Colors = {Red, Blue} Shapes = {Circle, Square}
Colors × Shapes = { (Red, Circle), (Red, Square), (Blue, Circle), (Blue, Square) }

Every color is paired with every shape, so every possible combination appears exactly once.

🔢 5. Number of ordered pairs

Multiply the size of A by the size of B. If A has two elements and B has three, the product contains six ordered pairs.

|A × B| = |A| × |B|
|A| = 2 |B| = 3 |A × B| = 2 × 3 = 6

For A = {1, 2, 3} and B = {X, Y}, there are 3 × 2 = 6 ordered pairs.

🔁 6. A × B is not B × A

A = {1, 2} B = {X, Y} A × B = {(1, X), (1, Y), (2, X), (2, Y)} B × A = {(X, 1), (X, 2), (Y, 1), (Y, 2)}
A × B ≠ B × A

The two products have the same number of pairs, but the pairs themselves are different because their order is reversed.

☕ 7. A real-life example

Drinks = {Tea, Coffee} Desserts = {Cake, Ice Cream}

Every possible drink-and-dessert meal is:

Drinks × Desserts = { (Tea, Cake), (Tea, Ice Cream), (Coffee, Cake), (Coffee, Ice Cream) }

📝 Worked practice

Let A = {1, 2} and B = {X, Y, Z}.

A × B = { (1, X), (1, Y), (1, Z), (2, X), (2, Y), (2, Z) } |A × B| = 2 × 3 = 6 A × B ≠ B × A

Lesson 6 · Mappings

Functions

A function is a rule that takes an input and produces exactly one output. Functions connect sets to probability, calculus, machine learning, and quantum mechanics.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a function is
  • Identify the domain and codomain
  • Read function notation
  • Evaluate a function for a given input
  • Check that every input has exactly one output

⚙️ 1. What is a function?

A function is a rule that maps each input to exactly one output.

f : A → B

Read this as “f is a function from A to B.”

Domain A = allowed inputs
Codomain B = possible outputs

🗺️ 2. A simple mapping

A = {1, 2, 3} B = {A, B, C} f(1) = A f(2) = B f(3) = C
Domain inputMappingCodomain output
1→A
2→B
3→C

Every number points to exactly one letter, so this is a valid function.

📥 3. Domain and codomain

Domain: all allowed inputs

A = {1, 2, 3}

The function accepts only inputs from this domain.

Codomain: all possible outputs

B = {Red, Blue, Green}

Every output produced by the function must belong to this codomain.

🧮 4. Reading function notation

f(x) = x + 1

This rule means: take the input x and add one.

f(1) = 1 + 1 = 2 f(3) = 3 + 1 = 4 f(10) = 10 + 1 = 11

☝️ 5. One input, exactly one output

Not a function 1 → A
1 → B

Input 1 has two outputs.

Valid function 1 → A
2 → A
3 → A

Different inputs may share one output.

The rule restricts each input to one output. It does not require different outputs.

👥 6. Functions in everyday life

Students mapped to ages

Alice → 18 Bob → 19 Charlie → 18

This is valid: each student has one age, and multiple students may share the same age.

Countries mapped to capitals

Japan → Tokyo France → Paris Brazil → Brasília

Each country maps to exactly one capital.

🔍 7. Evaluating functions

Substitute the given input wherever you see x, then simplify.

f(x) = 2x f(4) = 2(4) = 8 g(x) = x² g(5) = 5² = 25

Evaluate means “find the output for this input.”

🎲 8. Why functions matter

A probability function can map every outcome to a number from 0 to 1:

p : X → [0, 1]
X = {Heads, Tails} p(Heads) = 0.5 p(Tails) = 0.5

Here, X is the domain of outcomes and [0, 1] is the codomain of possible probability values.

🌟 Memory trick

Think of a vending machine: one input goes through a rule and produces one result.

Input → Function → Output
3 → f(x) = x + 2 → 5

📝 Worked practice

f(x) = x + 5 f(1) = 6 f(4) = 9 f(10) = 15 g(x) = 3x g(2) = 6
