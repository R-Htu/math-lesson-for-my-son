Lesson 1 · Foundations

What is a Set?

A set is a collection of distinct things. Those things can be numbers, words, objects, or even other sets.

📦 Collections and elements

Every item inside a set is called an element. We write elements between curly braces.

Fruits = {Apple, Banana, Orange} Numbers = {1, 2, 3, 4, 5}

The set Fruits has three elements. The symbol ∈ means “is an element of.”

True Apple ∈ Fruits
False Car ∈ Fruits

Not inside? Use ∉. For example, Car ∉ Fruits.

⚡ Four rules to remember

1. Sets usually use capital letters

A = {1, 2, 3} B = {Cat, Dog}

2. An empty set contains nothing

∅ = { }

3. Order does not matter

{1, 2, 3} = {3, 1, 2}

4. Repeated elements count only once

{1, 1, 2, 2, 3} = {1, 2, 3}

📏 Size of a set

The number of elements in a set is its cardinality. We write it with vertical bars.

A = {Dog, Cat, Bird} |A| = 3

Lesson 2 · Relationships

Subsets

A set is a subset of another set when every one of its elements also appears in the other set.

🗂 A smaller set inside a bigger set

Animals = {Cat, Dog, Bird, Fish} Pets = {Cat, Dog}

Every element of Pets appears in Animals, so we can write:

Pets ⊆ Animals

Read ⊆ as “is a subset of.” If even one element is missing from the larger set, it is not a subset.

Subset {2, 4} ⊆ {1, 2, 3, 4}
Not a subset {2, 5} ⊄ {1, 2, 3, 4}

🧠 The subset test

Look at each element in the smaller set and ask: Does it also appear in the bigger set?

CandidateSubset of A?Reason
{2, 5}YesBoth are in A
{1, 6}No6 is missing
{ }YesThe empty set is always a subset

Here, A = {1, 2, 3, 4, 5}.

📌 Two special rules

Every set is a subset of itself

A ⊆ A

The empty set is a subset of every set

∅ ⊆ A

There are no elements in ∅ that could break the subset rule.

Lesson 3 · Combinations

Power Sets

The power set of X is the set of every possible subset of X—including the empty set and X itself.

⚙️ A set made of sets

Suppose X = {A, B}. Its power set is written 𝒫(X).

𝒫(X) = { { }, {A}, {B}, {A, B} }

A normal set contains elements. A power set contains entire subsets as its elements.

🔢 How many subsets?

A set with n elements always has 2ⁿ subsets. Each element has two choices: included or not included.

|𝒫(X)| = 2ⁿ
Elements (n)CalculationTotal subsets

Turn the elements on or off. The lab lists every possible subset of your chosen set.

🎲 Why power sets matter

In probability, X is the sample space of all outcomes. An event is a subset of X, so it is also one element of 𝒫(X).

X = {Sunny, Rainy, Snowy} U = {Rainy, Snowy} U ⊆ X and U ∈ 𝒫(X)

Lesson 4 · Combining Sets

Set Operations

Set operations let us combine sets, find what they share, or remove elements. The three essentials are union, intersection, and difference.

Learning objectives

By the end of this lesson, you will be able to:

  • Combine sets using union (∪)
  • Find common elements using intersection (∩)
  • Remove elements using difference (− or \)
  • Solve simple set-operation problems

➕ 1. Union (∪)

The union combines every element from both sets. Think: “Everything in A or B.”

A = {1, 2, 3} B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

The number 3 appears only once because a set never counts duplicate elements.

Start A: 1 2 3
B: 3 4 5
Combine A ∪ B: 1 2 3 4 5

🎯 2. Intersection (∩)

The intersection contains only elements that appear in both sets. Think: “Common elements.”

A = {1, 2, 3} B = {3, 4, 5}
A ∩ B = {3}

Only 3 belongs to both A and B.

Compare A: 1 2 [3]
B: [3] 4 5
Keep common items A ∩ B: 3

➖ 3. Difference (−)

The difference starts with one set and removes every element found in the other set.

A = {1, 2, 3, 4} B = {3, 4, 5}
A − B = {1, 2}

Start with A, then remove 3 and 4 because they also occur in B.

B − A = {5}

Direction matters: A − B and B − A are usually different.

🍎 One example, three operations

A = {Apple, Banana, Mango} B = {Banana, Orange}
OperationMeaningResult
A ∪ BEverything{Apple, Banana, Mango, Orange}
A ∩ BCommon elements{Banana}
A − BIn A, but not B{Apple, Mango}
B − AIn B, but not A{Orange}

🌟 Memory trick

SymbolOperationRemember

📝 Worked practice

Let A = {1, 2, 3, 4} and B = {3, 4, 5, 6}.

A ∪ B = {1, 2, 3, 4, 5, 6} A ∩ B = {3, 4} A − B = {1, 2} B − A = {5, 6}

🎲 Why this matters

Set operations appear throughout probability. If two events U and V do not overlap, then their intersection is empty:

U ∩ V = ∅

The probability of either event occurring is then the sum of their individual probabilities:

P(U ∪ V) = P(U) + P(V)

Union tells us either event; intersection tells us whether the events overlap.

Lesson 5 · Pairing Sets

Cartesian Product

A Cartesian product pairs every element of one set with every element of another set. These ordered pairs are the bridge from sets to functions.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a Cartesian product is
  • Write and interpret ordered pairs
  • Find the Cartesian product of two sets
  • Calculate the number of ordered pairs
  • Explain why A × B is generally different from B × A

✖️ 1. What is a Cartesian product?

The Cartesian product of A and B is the set of all possible ordered pairs whose first value comes from A and second value comes from B.

A × B

Read this as “A cross B.” Pair every element of A with every element of B.

Imagine a multiplication table: every row meets every column, and each meeting creates one ordered pair.

📍 2. Ordered pairs

An ordered pair has two positions. The first value comes from A; the second comes from B.

(1, A)
First from A, second from B (1, A)
Different order (A, 1)

Order matters: (1, A) ≠ (A, 1).

🧩 3. Pair every element

A = {1, 2} B = {A, B}

Start with 1 and pair it with both elements of B. Then repeat with 2.

A × B = { (1, A), (1, B), (2, A), (2, B) }
From AFrom BOrdered pair
1A(1, A)
1B(1, B)
2A(2, A)
2B(2, B)

🎨 4. Colors and shapes

Colors = {Red, Blue} Shapes = {Circle, Square}
Colors × Shapes = { (Red, Circle), (Red, Square), (Blue, Circle), (Blue, Square) }

Every color is paired with every shape, so every possible combination appears exactly once.

🔢 5. Number of ordered pairs

Multiply the size of A by the size of B. If A has two elements and B has three, the product contains six ordered pairs.

|A × B| = |A| × |B|
|A| = 2 |B| = 3 |A × B| = 2 × 3 = 6

For A = {1, 2, 3} and B = {X, Y}, there are 3 × 2 = 6 ordered pairs.

🔁 6. A × B is not B × A

A = {1, 2} B = {X, Y} A × B = {(1, X), (1, Y), (2, X), (2, Y)} B × A = {(X, 1), (X, 2), (Y, 1), (Y, 2)}
A × B ≠ B × A

The two products have the same number of pairs, but the pairs themselves are different because their order is reversed.

☕ 7. A real-life example

Drinks = {Tea, Coffee} Desserts = {Cake, Ice Cream}

Every possible drink-and-dessert meal is:

Drinks × Desserts = { (Tea, Cake), (Tea, Ice Cream), (Coffee, Cake), (Coffee, Ice Cream) }

📝 Worked practice

Let A = {1, 2} and B = {X, Y, Z}.

A × B = { (1, X), (1, Y), (1, Z), (2, X), (2, Y), (2, Z) } |A × B| = 2 × 3 = 6 A × B ≠ B × A

Lesson 6 · Mappings

Functions

A function is a rule that takes an input and produces exactly one output. Functions connect sets to probability, calculus, machine learning, and quantum mechanics.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a function is
  • Identify the domain and codomain
  • Read function notation
  • Evaluate a function for a given input
  • Check that every input has exactly one output

⚙️ 1. What is a function?

A function is a rule that maps each input to exactly one output.

f : A → B

Read this as “f is a function from A to B.”

Domain A = allowed inputs
Codomain B = possible outputs

🗺️ 2. A simple mapping

A = {1, 2, 3} B = {A, B, C} f(1) = A f(2) = B f(3) = C
Domain inputMappingCodomain output
1→A
2→B
3→C

Every number points to exactly one letter, so this is a valid function.

📥 3. Domain and codomain

Domain: all allowed inputs

A = {1, 2, 3}

The function accepts only inputs from this domain.

Codomain: all possible outputs

B = {Red, Blue, Green}

Every output produced by the function must belong to this codomain.

🧮 4. Reading function notation

f(x) = x + 1

This rule means: take the input x and add one.

f(1) = 1 + 1 = 2 f(3) = 3 + 1 = 4 f(10) = 10 + 1 = 11

☝️ 5. One input, exactly one output

Not a function 1 → A
1 → B

Input 1 has two outputs.

Valid function 1 → A
2 → A
3 → A

Different inputs may share one output.

The rule restricts each input to one output. It does not require different outputs.

👥 6. Functions in everyday life

Students mapped to ages

Alice → 18 Bob → 19 Charlie → 18

This is valid: each student has one age, and multiple students may share the same age.

Countries mapped to capitals

Japan → Tokyo France → Paris Brazil → Brasília

Each country maps to exactly one capital.

🔍 7. Evaluating functions

Substitute the given input wherever you see x, then simplify.

f(x) = 2x f(4) = 2(4) = 8 g(x) = x² g(5) = 5² = 25

Evaluate means “find the output for this input.”

🎰 Function machine

For f(x) = 2x + 1, choose an input and watch the rule produce exactly one output.

🎲 8. Why functions matter

A probability function can map every outcome to a number from 0 to 1:

p : X → [0, 1]
X = {Heads, Tails} p(Heads) = 0.5 p(Tails) = 0.5

Here, X is the domain of outcomes and [0, 1] is the codomain of possible probability values.

🌟 Memory trick

Think of a vending machine: one input goes through a rule and produces one result.

Input → Function → Output
3 → f(x) = x + 2 → 5

📝 Worked practice

Lesson 7 · Connections

Relations

A relation describes connections between elements of sets. Functions are special relations with one strict rule: every input must have exactly one output.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what a relation is
  • Interpret relations as sets of ordered pairs
  • Create relations between two sets
  • Distinguish a relation from a function
  • Recognize that every function is a special relation

🔗 1. What is a relation?

A relation records which elements of one set are connected to elements of another set.

A = {1, 2, 3} B = {A, B, C} 1 → A 2 → B 3 → C

Write each connection as an ordered pair, then collect the pairs in a set:

R = {(1, A), (2, B), (3, C)}

📍 2. Ordered pairs still have direction

In (a, b), the first element is a and the second is b. Swapping the positions changes the pair.

(1, 2) ≠ (2, 1)

Think (first, second). Relations preserve this order.

✖️ 3. Relations come from Cartesian products

A = {1, 2} B = {a, b} A × B = {(1, a), (1, b), (2, a), (2, b)}

A relation from A to B selects any collection of these possible ordered pairs.

One relation R₁ = {(1, a), (2, b)}
Another relation R₂ = {(1, a), (1, b), (2, a)}
R ⊆ A × B

Every subset of A × B is a relation from A to B.

🗺️ 4. Visualizing a relation

A = {1, 2, 3} B = {a, b, c} R = {(1, a), (2, b), (3, a)}
Input from AConnectionOutput in B
1→a
2→b
3→a

Different inputs may connect to the same output. That is completely valid.

🧭 5. Relations are flexible

An input may have no output R = {(1, a), (2, b)}

Input 3 is unconnected. This is still a relation.

An input may have many outputs R = {(1, a), (1, b), (2, c)}

Input 1 has two connections. Still a relation.

Both examples fail the stricter function rule, but neither breaks the definition of a relation.

⚖️ 6. Relation versus function

Every function is a relation.
Not every relation is a function.

🔢 8. The “less than” relation

Let A = {1, 2, 3} and define x R y when x < y.

1 < 2 ✓ 1 < 3 ✓ 2 < 3 ✓
R = {(1, 2), (1, 3), (2, 3)}

Here, x R y means “x is related to y by R.” Thus 2 R 3 is true, while 3 R 2 is false.

Students enrolled in classes

Bob can connect to two classes because a relation permits multiple outputs.

People who have visited countries

Alice → Japan Alice → France Bob → Japan

Relations naturally describe many-to-many connections.

In probability and quantum mechanics, this language describes connections among outcomes, probabilities, states, measurements, vectors, and operators.

Lesson 8 · Classifying Relations

Properties of Relations

Relations become more useful when we classify how their connections behave. Four key tests—reflexive, symmetric, antisymmetric, and transitive—reveal the structure.

Learning objectives

By the end of this lesson, you will be able to:

  • Recognize reflexive, symmetric, antisymmetric, and transitive relations
  • Test a relation for each property
  • Distinguish symmetric from antisymmetric
  • Identify an equivalence relation

🔎 1. Start with a relation on one set

A relation on A is a subset of A × A. For example:

A = {1, 2, 3} R = {(1, 1), (2, 2), (3, 3)}

We now ask which properties R has by inspecting the pairs it contains—or is missing.

🪞 2. Reflexive: SELF

A relation is reflexive when every element is related to itself.

For every a ∈ A, (a, a) ∈ R
A = {1, 2, 3} Required self-pairs: (1, 1) ✓ (2, 2) ✓ (3, 3) ✓

So R = {(1,1), (2,2), (3,3), (1,2)} is reflexive. Extra pairs do not hurt.

Memory: Reflexive = SELF. Everybody must point to themselves.

↔️ 3. Symmetric: BACK

A relation is symmetric when every connection also appears in the reverse direction.

(a, b) ∈ R ⇒ (b, a) ∈ R
Symmetric R = {(1,2), (2,1)}

Every arrow has a return arrow.

Not symmetric R = {(1,2)}

The pair (2,1) is missing.

The real-life relation “is a sibling of” is generally symmetric: if Alice is Bob’s sibling, Bob is Alice’s sibling.

🚫 4. Antisymmetric: no different two-way pair

A relation is antisymmetric when two different elements cannot be connected in both directions.

(a, b) ∈ R and (b, a) ∈ R ⇒ a = b
Antisymmetric R = {(1,1), (2,2), (1,2)}

There is no reverse pair (2,1).

Not antisymmetric R = {(1,2), (2,1)}

1 and 2 differ but connect both ways.

Important: Antisymmetric does not mean “never symmetric.” A relation containing only self-pairs can be both symmetric and antisymmetric.

⛓️ 5. Transitive: CHAIN

A relation is transitive when two connected steps guarantee the direct shortcut.

(a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R
Transitive R = {(1,2), (2,3), (1,3)}

The required shortcut (1,3) exists.

Not transitive R = {(1,2), (2,3)}

The required pair (1,3) is missing.

The relation “less than” is transitive: 1 < 2 and 2 < 3 imply 1 < 3.

🟰 8. Equivalence relations

An equivalence relation must have exactly three properties:

Reflexive + Symmetric + Transitive

Memory: Equivalence relation = R + S + T.

Example: “has the same age”

  • Everyone has the same age as themselves → reflexive
  • If Alice has Bob’s age, Bob has Alice’s age → symmetric
  • If Alice and Bob share an age, and Bob and Chen share it, then Alice and Chen share it → transitive

Therefore, “has the same age” is an equivalence relation.

🧺 9. Equivalence classes

Equivalence relations group elements that are equivalent. On A = {1,2,3,4,5,6}, relate numbers with the same parity.

Odd class {1, 3, 5}
Even class {2, 4, 6}

These non-overlapping groups are called equivalence classes.

🌙 10. The big picture

Sets ↓ Cartesian products ↓ Relations ├──→ Functions └──→ Equivalence relations ↓ Equivalence classes

Lesson 9 · Grouping Equivalent Elements

Equivalence Classes & Partitions

An equivalence relation groups elements that count as “the same” for a chosen purpose. Those groups are equivalence classes, and together they partition the original set.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain what an equivalence class is
  • Find the equivalence class of an element
  • Recognize valid partitions of sets
  • Explain how equivalence relations create partitions

🔁 1. Quick review

An equivalence relation has three properties:

Reflexive + Symmetric + Transitive

What does such a relation actually do? It separates a set into groups of equivalent elements.

🧺 2. What is an equivalence class?

Let A = {1, 2, 3, 4, 5, 6}. Relate two numbers when they have the same parity—both odd or both even.

Odd equivalence class {1, 3, 5}
Even equivalence class {2, 4, 6}

Each class is a group of elements considered equivalent by the relation.

🏷️ 3. The class of an element

The notation [a] means “the equivalence class containing a.”

[1] = {1, 3, 5} [3] = {1, 3, 5} [5] = {1, 3, 5} [2] = {2, 4, 6} [4] = {2, 4, 6} [6] = {2, 4, 6}
1 ~ 3 ⇒ [1] = [3]

If two elements are equivalent, they belong to exactly the same equivalence class.

🚧 4. Classes cannot partially overlap

{1, 3, 5} ∩ {2, 4, 6} = ∅

Two equivalence classes are either completely separate or actually the same class. Partial overlap is impossible.

If two classes share even one element, equivalence forces the two classes to be identical.

🧩 5. What is a partition?

A partition divides a set into non-empty, non-overlapping groups that include every element.

P = {{1, 3, 5}, {2, 4, 6}}
Partition ruleQuestion to ask
Everything is includedDoes every element belong to a group?
No overlapDo different groups share no elements?
No empty groupsDoes every group contain something?

✅ 6. Testing partitions

🔗 7. Equivalence relations create partitions

Equivalence relation ↓ groups related elements Equivalence classes ↓ are separate and cover the set Partition

This connection also works in reverse: every partition defines an equivalence relation by declaring two elements equivalent when they belong to the same group.

🏫 9. A real-life partition

Relate students who belong to the same classroom.

Class A = {Alice, Bob} Class B = {Charlie, David} Class C = {Emma, Frank} [Bob] = {Alice, Bob} [David] = {Charlie, David} [Emma] = {Emma, Frank}

The classrooms partition the students because each student belongs to exactly one non-empty class.

🎲 10. Connection to probability

Probability begins with a sample space Ω containing all possible outcomes. Events are subsets of Ω.

Ω = {H, T} Possible events: ∅, {H}, {T}, {H, T}

Your work with sets, power sets, and set operations already provides the language needed to study probability spaces.

🌙 11. The big picture

Set theory ↓ Cartesian products ↓ Relations ├──→ Functions └──→ Equivalence relations ↓ Equivalence classes ↓ Partitions

In more advanced mathematics, treating each class as a single object leads to quotient sets.

Lesson 10 · Set Theory Meets Physics

Classical Physics on a Finite Phase Space

The symbols in a physics textbook become manageable when we read them using sets and functions. This lesson connects finite configurations directly to probability distributions, events, measures, random variables, and spectra.

Learning objectives

By the end of this lesson, you will understand:

  • Finite configuration spaces and why 2ᴺ appears
  • Why YZ denotes a set of functions
  • Events, probability distributions, and probability measures
  • Conditional probability
  • Random variables and their spectra

📦 1. Finite configuration spaces

A configuration space X contains every possible state of a physical system. The book begins with X finite, meaning it has only finitely many configurations.

One coin: X = {H, T} Two coins: X = {HH, HT, TH, TT} Three coins: |X| = 8

A system has one actual configuration, but probability lets us describe uncertainty about which configuration it is in.

💾 2. N bits and the meaning of 2ᴺ

Each bit has two possible values, {0,1}. An N-bit configuration chooses one value for every bit.

X = {0,1}ᴺ    and    |X| = 2ᴺ

Lesson 11 · Probability Foundations

Probability Spaces & Events

A probability space organizes three things: possible outcomes, the events we can ask about, and a rule assigning a probability to every event.

Learning objectives

By the end of this lesson, you will understand:

  • Sample spaces, outcomes, and events
  • Why the power set represents all events in a finite model
  • Probability distributions and probability measures
  • The probability-space notation (X, 𝒫(X), P)
  • The difference between p(x) and P(U)

🎲 1. Sample space and outcome

The sample space X is the set of every possible result of an experiment. An outcome is one element of X.

Coin toss X = {H, T}

H and T are individual outcomes.

Six-sided die X = {1,2,3,4,5,6}

For example, 4 ∈ X.

X = all possible outcomes

🎯 2. Events are subsets

An event collects the outcomes that make a statement true.

Die sample space: X = {1,2,3,4,5,6} U = {4} “roll a 4” V = {2,4,6} “roll an even number” W = {1,2,3} “roll less than 4”
Event U ⊆ X

An event may contain one outcome, many outcomes, no outcomes, or every outcome.

⚫ 3. Impossible and certain events

Impossible event ∅ ⊆ X
P(∅) = 0

Example: rolling a 7 on a standard die.

Certain event X ⊆ X
P(X) = 1

Some outcome in X must happen.

📦 4. Power set = all events

Because events are subsets, the power set 𝒫(X) contains every event.

X = {H, T} 𝒫(X) = { ∅, impossible {H}, Heads {T}, Tails {H,T} certain }
|𝒫(X)| = 2|X|

Two outcomes create four events; three outcomes create eight events.

⚖️ 5. Probability measure

A probability measure P is a function taking an event as input and returning a number between 0 and 1.

P : 𝒫(X) → [0,1]
Event → Probability measure → Probability {H} → P → 0.5 {H,T} → P → 1

For finite X, add the outcome probabilities inside U to obtain its event probability:

P(U) = ∑x∈U p(x)

p(1) = p(2) = ··· = p(6) = 1/6 U = {2,4,6} P(U) = p(2) + p(4) + p(6) = 1/6 + 1/6 + 1/6 = 1/2

If events overlap, adding their probabilities counts the intersection twice. Subtract it once:

P(U ∪ V) = P(U) + P(V) − P(U ∩ V)

P(U ∪ V) = P(U) + P(V)

Disjoint means the events have no outcomes in common.

Knowing V shrinks the possible world from six outcomes to {4,5,6}; two of those three are even.

Lesson 12 · Event Calculations

Probability Rules

Probability formulas come directly from the set operations you already know. Complements, unions, intersections, and conditional probabilities describe how events combine.

Learning objectives

By the end of this lesson, you will understand:

  • Complements of events
  • Union and intersection probabilities
  • Disjoint events and the addition rule
  • Why overlapping probabilities require subtraction
  • Conditional probability and the multiplication rule
  • The difference between independent and disjoint events

🧩 1. Events use set operations

An event is a subset U ⊆ X, so probability uses familiar set operations:

Set expressionEvent meaning
U ∪ VU or V—or both
U ∩ VU and V
U − VU but not V
UᶜNot U

🌗 2. Complement of an event

The complement contains everything in X that is not in U.

Uᶜ = X − U
X = {1,2,3,4,5,6} U = {2,4,6} even Uᶜ = {1,3,5} not even

Either U happens or it does not, so their probabilities total one:

P(Uᶜ) = 1 − P(U)

Here, P(U)=1/2, so P(Uᶜ)=1−1/2=1/2.

🔀 3. Union and intersection

Let U={2,4,6} and V={4,5,6} for a fair die.

Union: U or V U ∪ V = {2,4,5,6}
Intersection: U and V U ∩ V = {4,6}
P(U ∩ V) = 2/6 = 1/3

🚧 4. Disjoint events

Two events are disjoint when they cannot happen together.

U ∩ V = ∅
U = {1,2} V = {5,6} U ∩ V = ∅

Nothing is counted twice, so their union probability is a simple sum:

P(U ∪ V) = P(U) + P(V)

➕ 5. General addition rule

For overlapping events, adding P(U) and P(V) counts the intersection twice. Subtract it once.

P(U ∪ V) = P(U) + P(V) − P(U ∩ V)
P(U) = 1/2 P(V) = 1/2 P(U ∩ V) = 1/3 P(U ∪ V) = 1/2 + 1/2 − 1/3 = 2/3

Why subtract? The shared outcomes were included once in U and once again in V.

🔍 6. Conditional probability

P(U | V) asks for the probability of U after learning that V occurred.

P(U | V) = P(U ∩ V) / P(V),   P(V) > 0
U = {2,4,6} even V = {4,5,6} greater than 3 U ∩ V = {4,6} P(U ∩ V) = 1/3 P(V) = 1/2 P(U | V) = (1/3) ÷ (1/2) = 2/3

Knowing V shrinks the possible outcomes to {4,5,6}, and two of those three are even.

✖️ 7. Multiplication rule

Rearrange the conditional-probability formula by multiplying both sides by P(V):

P(U ∩ V) = P(U | V)P(V)

This form is useful when you know a conditional probability and need the probability that both events occur.

🔓 8. Independence preview

Events U and V are independent when knowing V happened does not change the probability of U.

P(U | V) = P(U)

Combining this with the multiplication rule gives the standard independence test:

P(U ∩ V) = P(U)P(V)

🪙 9. Independent coin flips

X = {HH, HT, TH, TT} U = {HH, HT} first flip is H V = {HH, TH} second flip is H P(U) = 1/2 P(V) = 1/2 U ∩ V = {HH} P(U ∩ V) = 1/4
1/4 = (1/2)(1/2)

The equality proves U and V are independent: the first flip does not affect the second.

⚠️ 10. Independent is not disjoint

ConceptMeaningTest
DisjointCannot occur togetherU ∩ V = ∅
IndependentKnowing one gives no information about the otherP(U ∩ V)=P(U)P(V)

If U and V have positive probability and are disjoint, then P(U ∩ V)=0 while P(U)P(V)>0. Therefore, they cannot also be independent.

📝 Worked die practice

For a fair die, let U={2,4,6} and V={3,4,5,6}.

U ∩ V = {4,6} U ∪ V = {2,3,4,5,6} Uᶜ = {1,3,5} P(U) = 1/2 P(V) = 2/3 P(U ∩ V) = 1/3 P(U ∪ V) = 5/6 P(U | V) = (1/3) ÷ (2/3) = 1/2 P(U)P(V) = (1/2)(2/3) = 1/3 Therefore U and V are independent.

Lesson 13 · Events Without Influence

Independence

Two events are independent when learning that one occurred gives no new information about the other. This idea turns many complicated joint probabilities into multiplication.

Learning objectives

By the end of this lesson, you will be able to:

  • Explain independence intuitively
  • Test independence using intersections
  • Connect independence with conditional probability
  • Distinguish independent from disjoint events
  • Calculate probabilities for independent experiments

🪙 1. What does independent mean?

Flip a coin twice. Whether the first flip is H or T, the second flip still has probability 1/2 of Heads.

Knowing one event does not change the other.
First flip H → second flip is still H or T First flip T → second flip is still H or T

🔍 2. Conditional-probability test

If V gives no information about U, then conditioning on V leaves U’s probability unchanged.

P(U | V) = P(U)

Likewise, when the conditional probability is defined:

P(V | U) = P(V)

✖️ 3. The main independence formula

Start with P(U|V)=P(U∩V)/P(V). If P(U|V)=P(U), multiply by P(V):

P(U ∩ V) = P(U)P(V)

This product test works even when a conditional probability would involve a zero-probability event, so it is the standard definition.

✅ 4. Two independent coin flips

X = {HH, HT, TH, TT} U = {HH, HT} first flip is Heads V = {HH, TH} second flip is Heads P(U) = 2/4 = 1/2 P(V) = 2/4 = 1/2 U ∩ V = {HH} P(U ∩ V) = 1/4
P(U)P(V) = (1/2)(1/2) = 1/4

Because P(U∩V)=P(U)P(V), the events are independent.

❌ 5. A dependent die example

X = {1,2,3,4,5,6} U = {2,4,6} even V = {4,5,6} greater than 3 P(U) = 1/2 P(V) = 1/2 U ∩ V = {4,6} P(U ∩ V) = 1/3 P(U)P(V) = 1/4
1/3 ≠ 1/4

Therefore, U and V are dependent.

🧠 6. The same example conditionally

P(U | V) = P(U ∩ V) / P(V) = (1/3) ÷ (1/2) = 2/3 But P(U) = 1/2

Learning that the result exceeds 3 changes the probability of an even result from 1/2 to 2/3. That change means dependence.

🚧 8. Independent does not mean disjoint

Die events U={1}, V={2}: P(U ∩ V) = 0 disjoint P(U)P(V) = (1/6)(1/6) = 1/36 0 ≠ 1/36, so they are not independent.

Two disjoint events with positive probabilities cannot be independent.

🎲 9. Independent experiments

A coin flip and a die roll do not affect each other. Multiply their probabilities for a combined result.

P(Heads and 6) = (1/2)(1/6) = 1/12

For three independent fair coins:

P(HHH) = (1/2)³ = 1/8

More generally, for suitably independent events:

P(A ∩ B ∩ C) = P(A)P(B)P(C)

⚡ 10. Why independence matters

Independence replaces a difficult joint calculation with multiplication.

P(A) = 0.2 P(B) = 0.5 If independent: P(A ∩ B) = 0.2 × 0.5 = 0.1

Lesson 14 · Numerical Quantities

Random Variables & Expectation

A random variable turns each possible outcome into a number. Its expectation combines those numerical values with their probabilities to describe the long-run average.

Learning objectives

  • Interpret a random variable as a function f : X → ℝ
  • Find its spectrum
  • Calculate expected value
  • Connect expectation to physical observables

🔢 1. Random variable = numerical function

f : X → ℝ

Each outcome x receives exactly one real-number value f(x).

X = {H, T} f(H) = 1 f(T) = 0

The name “random” refers to the uncertain input x; the function itself is fixed.

✨ 2. Spectrum

The spectrum is the set of values the random variable can produce.

σ(f) = {f(x) | x ∈ X}
For f(H)=1 and f(T)=0: σ(f) = {0,1}

⚖️ 3. Expected value

Multiply every possible value by the probability of its outcome, then add.

E[f] = ∑x∈X f(x)p(x)
X = {1,2,3} p(1)=0.2, p(2)=0.5, p(3)=0.3 f(x)=x E[f] = 1(0.2)+2(0.5)+3(0.3) = 2.1

Expectation need not be a possible outcome. It is a probability-weighted center.

🎲 4. Fair-die expectation

X = {1,2,3,4,5,6} p(x)=1/6 f(x)=x E[f] = (1+2+3+4+5+6)/6 = 21/6 = 3.5

You can never roll 3.5, but repeated rolls average toward 3.5.

🌙 5. Physical observable

If f assigns an energy, position, or other measurable number to every physical state, then f is an observable quantity and E[f] is its average value under distribution p.

State x → probability p(x) State x → measured quantity f(x) Combine them → E[f]

Lesson 15 · Measuring Fluctuations

Expectation, Variance & Fluctuations

Expectation locates the average value. Variance answers the next question: how widely do the possible values fluctuate around that average?

Learning objectives

By the end of this lesson, you will be able to:

  • Review and calculate expected value
  • Explain why averages do not describe spread
  • Calculate variance by definition and by shortcut
  • Interpret standard deviation
  • Connect variance with physical fluctuations

⚖️ 1. Review: expected value

E[f] = ∑x∈X f(x)p(x)
X = {1,2,3} p(1)=0.2, p(2)=0.5, p(3)=0.3 f(x)=x E[f] = 1(0.2)+2(0.5)+3(0.3) = 2.1

The expected value gives the probability-weighted center.

📏 2. Why the mean is not enough

Two systems can share mean 10 but behave very differently.

Small spread 9, 10, 10, 11

Values cluster near 10.

Large spread 1, 10, 10, 19

Values reach far from 10.

Variance distinguishes these situations.

↔️ 3. Deviations from the mean

The deviation of a value is f(x)−E[f]. Deviations can be positive or negative.

Mean = 10 Value 13: 13−10 = 3 Value 7: 7−10 = −3

Averaging raw deviations always produces zero because positive and negative differences cancel. Squaring prevents that cancellation.

(f − E[f])²

📊 4. Variance definition

Variance is the expected squared distance from the mean.

Var(f) = E[(f − E[f])²]

Interpretation: expectation asks “where is the center?” Variance asks “how spread out are the values?”

🧮 5. Calculate variance step by step

Let X={1,2,3}, each with probability 1/3, and f(x)=x.

f(x)Deviation from E[f]=2Squared deviationWeighted value
1−111/3
2000
3111/3
Var(f) = 1/3 + 0 + 1/3 = 2/3

📐 6. Standard deviation

σf = √Var(f)
σf = √(2/3) ≈ 0.816

Variance uses squared units; standard deviation returns to the original units and is often easier to interpret.

⚡ 7. Variance shortcut

Var(f) = E[f²] − E[f]²

This follows by expanding (f−E[f])² and using linearity of expectation.

E[f] = 2 E[f²] = (1²+2²+3²)/3 = 14/3 Var(f) = 14/3 − 2² = 14/3 − 12/3 = 2/3

The shortcut and definition give the same answer.

0️⃣ 8. Zero variance

If f(x)=5 for every outcome, then every value equals its mean and every deviation is zero.

Constant function ⇒ Var(f) = 0

Zero variance means no uncertainty in the value of f.

⚛️ 9. Physical interpretation

If f represents a system’s energy, then:

Expectation E[f]

Average energy.

Variance Var(f)

Energy fluctuation around the average.

Classical probability develops these ideas before quantum theory introduces analogous structures for observables and measurement.

🔋 10. Energy example

Energy values: 10, 20, 30 Probabilities: 0.2, 0.5, 0.3 E[E] = 10(0.2)+20(0.5)+30(0.3) = 21 E[E²] = 100(0.2)+400(0.5)+900(0.3) = 490 Var(E) = 490−21² = 49 σE = √49 = 7
Average energy = 21, standard deviation = 7

🌙 11. The complete structure

States: x ∈ X Probabilities: p : X → [0,1] Quantity: f : X → ℝ Spectrum: σ(f) = {f(x) | x ∈ X} Average: E[f] = Σ f(x)p(x) Fluctuation: Var(f) = E[(f−E[f])²] Typical spread: σf = √Var(f)

📝 Worked practice

Let probabilities be 0.2, 0.5, 0.3 and values be 10, 20, 30.

E[f] = 21 E[f²] = 490 Var(f) = 490−21² = 49 σf = √49 = 7

🎲 Fair-die results

E[f] = 7/2 = 3.5 E[f²] = 91/6 ≈ 15.167 Var(f) = 91/6 − (7/2)² = 35/12 ≈ 2.917 σf = √(35/12) ≈ 1.708
